Core Features

Built specifically for CS & Engineering students

Local NLP Classification

Automatically categorizes notes into 12 predefined computer science subjects like Operating Systems, Java, DBMS, and Networks without paid AI APIs.

Duplicate Note Guard

Uses string sequence analysis to warn you if a similar handwritten note has already been saved into the database.

PDF & TXT Export

Generates clean PDF documents complete with metadata badges, confidence metrics, and formatted text for easy revision.
